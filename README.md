# CSE 210 Programming Projects

This repository contains all programming projects and exercises completed during the **CSE 210 - Programming with Classes** course. The course focuses on object-oriented programming principles using C# and includes weekly exercises that build upon fundamental programming concepts.

## 🌐 GitHub Pages

Visit the project portfolio: **[CSE 210 Projects Website](https://rafeleduardo.github.io/cse210-project-repp/)**

## 📚 Course Content

This repository is organized by weeks, each containing specific programming exercises:

- **Week 01** - C# Fundamentals (Variables, I/O, Conditionals, Loops, Functions)
- **Week 02** - Data Structures (Journal Application, Resume Builder)
- **Week 03** - Object Design (Classes and Encapsulation)
- **Week 04** - Inheritance and Polymorphism
- **Week 05** - Advanced Object-Oriented Programming
- **Week 06** - Design Patterns (Shapes Application, Eternal Quest Game)
- **Week 07** - Final Projects (Exercise Tracking System)

## 🛠️ Technologies Used

- **C#** - Primary programming language
- **.NET** - Framework and runtime
- **Visual Studio** - Development environment
- **JSON** - Data storage format
- **Object-Oriented Programming** - Core programming paradigm

## 🌟 Featured Projects

### 📔 Journal Application
A personal journaling system with JSON storage and reflective prompts for daily entries. Demonstrates file I/O operations and data persistence.

### ⚔️ Eternal Quest Game
A text-based adventure game implementing object-oriented design patterns and game mechanics. Showcases inheritance and polymorphism.

### 🏃‍♂️ Exercise Tracking System
A comprehensive fitness tracking application with exercise logging and progress monitoring. Final capstone project demonstrating all learned concepts.

### 🔺 Shapes Application
Geometric shapes calculator demonstrating inheritance and polymorphism principles with area and perimeter calculations.

## 🚀 Getting Started

1. Clone the repository
2. Open `cse210-ww-student-template.sln` in Visual Studio
3. Build and run individual projects from their respective week folders
